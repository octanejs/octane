The data worker sends a reply, a restored value, or any other message that JSON keeps exactly to its tabs as JSON text, and the tab parses it. That's faster to receive than a structured clone of the same objects. In Chromium, a tab takes a 20,000-row reply the worker validated in 3.1 ms instead of 5.5 ms. A tab says it reads text when it connects, so a tab from an earlier version still gets objects.
