# @octanejs/vaul

The Octane migration target for `vaul@1.1.2`.

## Installation

```sh
npm install @octanejs/vaul
pnpm add @octanejs/vaul
```

```ts
import { Drawer } from '@octanejs/vaul';
import '@octanejs/vaul/style.css';
```

The binding preserves Vaul's drawer component names, controlled and
uncontrolled state, directions, drag behavior, snap points, nested drawers,
portal/focus semantics, and `data-vaul-*` styling contract.

See [UPSTREAM.md](./UPSTREAM.md) for the immutable source and license evidence.
