# Mantine Hooks upstream contract

This port targets MIT-licensed `@mantine/hooks@9.5.0`, commit
`bb3d25ca42244e996a73e49f6ad94d0047f607d9`, with npm archive SHA-256
`ebe0f2a2958bf0fc82164bd3def77be8315778d0607de96b0d5977c211a4839a`.

The package claims the complete runtime export surface, adapted to Octane hook
slots, lifecycle, and native DOM events. The bounded shared-fixture lane proves
counter bounds, disclosure opening, and list append rendering. Existing broad
conformance, SSR, and type tests remain repository-authored evidence. Because
the pristine upstream runtime and type suites are not vendored and adapted
one-for-one, the manifest remains `recorded-unverified`.
