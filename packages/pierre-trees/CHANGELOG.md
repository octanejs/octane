# @octanejs/pierre-trees

## 0.0.1

### Patch Changes

- 134d36c: Add `@octanejs/pierre-trees`, an Octane port of `@pierre/trees/react` from `@pierre/trees` 1.0.0-beta.6. It provides the `FileTree` component (host props, the `header` slot, `renderContextMenu`, and `preloadedData` server rendering and hydration) and the `useFileTree`, `useFileTreeSelector`, `useFileTreeSelection` and `useFileTreeSearch` hooks, over the framework-neutral `@pierre/trees` model.
