## Source boundary and licensing

`@blocknote/react` is licensed MPL-2.0, which is outside this repository's
approved copy list (MIT, Unlicense, BSD-3-Clause, Apache-2.0). No upstream
source, declaration, stylesheet, or test is vendored, copied, or adapted here.

The Octane adapter is independently authored and MIT licensed. It was written
from a behavior and API contract derived from BlockNote's public documentation
and public API names, by an implementer who did not read the `@blocknote/react`
source. `@blocknote/core` stays an ordinary MPL-2.0 dependency and supplies the
editor, schemas, and `@blocknote/core/style.css`.

An earlier private scaffold of this package was generated by mechanically
copying upstream source. That scaffold was removed in full before this surface
was written.

## Supported surface

Headless only: `BlockNoteViewRaw`, `BlockNoteViewEditor`, `BlockNoteContext`,
`useBlockNoteContext`, `useCreateBlockNote`, `useBlockNoteEditor`,
`useEditorChange`, `useEditorSelectionChange`, and `usePrefersColorScheme`.
This matches upstream `BlockNoteViewRaw` rendered without a components context,
where every default UI element is disabled.

Not provided: the default UI (`BlockNoteView` from UI-kit packages,
`BlockNoteDefaultUI`, `ComponentsContext`, toolbars, menus, side menu, table
handles, comments), custom React block/inline/style specs, and the
`@blocknote/react/style.css` stylesheet.
