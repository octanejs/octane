# usehooks-ts upstream contract

This binding targets MIT-licensed `usehooks-ts@3.1.1`, tag commit
`61949134144d3690fe9f521260a16c779a6d3797`. The npm archive SHA-256 is
`bc0080ec78244f8d7adeddcad45b270d726e599e6ead2e8183b42bbf97f1701a`.

The supported export cohort and deferred browser, storage, media, observer,
and DOM-event hooks are enumerated in `status.json`. The shared React lane
exercises useBoolean, useCounter, useToggle, useMap, and useStep across a full
interaction sequence. Timing/lifecycle tests remain repository conformance
evidence. The pristine upstream runtime/type suites are not vendored or
adapted one-for-one, so provenance remains `recorded-unverified`.
